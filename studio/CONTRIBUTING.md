# Contributing

Read AGENTS.md and docs/INDEX.md. Use Node 24+, npm ci and the committed lockfile. Propose focused changes from testing; use Conventional Commits and include behavior, validation, limitations and documentation in each review. Add components through the versioned schema/registry/renderer rather than injecting arbitrary HTML. Keep imported packages data-only. Do not commit credentials, databases or personal media. New original contributions are AGPL-3.0-only; preserve third-party notices.
