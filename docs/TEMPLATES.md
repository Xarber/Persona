# Template system

All templates declare schema version 1 through their generated documents. They are fully editable independent copies; changing a factory does not overwrite existing sites. Thumbnails render the actual template document in a scaled frame rather than using a screenshot of a different implementation. Template content is demonstration content, not verified user accomplishments.

| Template | Category | Distinct structure |
| --- | --- | --- |
| Still | Minimal | Quiet hero, selected work, personal statement, contact |
| Terminal | Developer | Bordered technical hero, skills, three-column projects, timeline |
| Offbeat | Creative | Oversized right-aligned typography, rotated manifesto quote, staggered work |
| Fieldnotes | Student | Rounded introductory panel, education/experience timeline before projects, skills |
| Forma | Professional | Split-column formal hero, profile, experience and a principle statement |
| Chapter | Editorial | Centered serif title, narrative quote, biography and horizontal story cards |

Blank creation keeps a navigation bar, a heading and footer. Guided setup adds the supplied name to a selected starter without requiring AI or a long questionnaire. Portfolio fields can be skipped.

Export an editable project and import it to reuse a customized design on another installation. That uses the same bounded Persona project package and checksummed assets as project transfer. A separately managed, community template catalog/version-update installer is not implemented; do not imply that updating a template propagates into customized sites.
