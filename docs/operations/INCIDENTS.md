# Persona incidents

Treat widespread outage or data loss as SEV1, publishing or authentication failure as SEV2, limited degradation as SEV3, and cosmetic defects as SEV4. Record UTC timestamps, impact, commit, and redacted evidence. Compare external HTTPS with loopback health to isolate proxy and service failures. Restore the last compatible image only when application rollback is indicated. Recheck account and publishing flows before closing the incident.
